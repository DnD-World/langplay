# Standards

This repo follows strav's repo standards (`repo standards/STANDARDS.md` in CLAUDE SPACE).

Differences for this repo:

- **No installer** (§6 does not apply): Langplay is a website.
- **Hosting is Lovable** (merges sync into the Lovable project; publish from Lovable). An optional Cloudflare Workers copy is described in DEPLOY.md.
- **Local dev port:** 20136 (recorded in PORTS.md). Lovable's own sandbox uses 8080.
- **Docs site (§7):** not yet — the repo is private work in progress on DnD-World. The in-app `/docs` page covers users until the move to Stravelakis at v1.0.0.
